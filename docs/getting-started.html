Getting Started

Install the environment, resolve the common CUDA and uv setup failures, download the public TopBrain CTA data, and train your first 3D vessel reconstruction from sparse X-ray views.

1 Prerequisites

  • uv
  • Python 3.10
  • Linux x86_64
  • CUDA 11.8 toolkit with nvcc
  • NVIDIA GPU with ≥ 8 GB VRAM
Supported Target

This repository targets a pinned GPU Linux environment. For reproducible source builds, stay on Linux x86_64, Python 3.10, and a CUDA 11.8 toolkit that matches the pinned PyTorch build.

2 Installation

For most local machines, the short path is: 

uv python install 3.10
./scripts/uv.sh sync --verify

If you need help installing uv, setting up CUDA 11.8, or working on a cluster, expand the section below.

Install and troubleshooting details

What You Need to Install First

This repository assumes a Linux machine or cluster login node with:

  • uv for Python and dependency management
  • CUDA 11.8 with nvcc available in the shell used for installation
  • build tools such as gcc, g++, curl, and unzip

Official downloads and references:

  • uv installation guide
  • CUDA Toolkit archive
  • CUDA 11.8 Linux installation guide

Environment Variables

The wrapper script reads these variables. You only need them when autodetection is not sufficient.

VariablePurposeDefault
CUDA_HOME Path to the CUDA 11.8 toolkit root Auto-detected from nvcc on PATH
CUDA_MATH_ROOT Separate math-library root for split NVHPC layouts Not set
CC / CXX C / C++ compiler gcc / g++
UV_CACHE_DIR uv cache location .uv-cache in the repo root

If Autodetection Fails

Set CUDA_HOME explicitly and make sure nvcc is on PATH:

export CUDA_HOME=/path/to/cuda-11.8
export PATH="$CUDA_HOME/bin:$PATH"
./scripts/uv.sh sync --verify

NVHPC Split Layouts

Some NVHPC installs split CUDA math headers and libraries out of the default toolkit root. If TIGRE fails on CUDA math headers such as curand_kernel.h, set CUDA_MATH_ROOT: 

export CUDA_MATH_ROOT=/path/to/math_libs/11.8/targets/x86_64-linux
./scripts/uv.sh sync --verify

On some clusters you may also need CPATH or LIBRARY_PATH to point at that split math installation.

Verification

Rerun the full environment check at any time:

./scripts/uv.sh verify

For a deeper runtime check covering imports, GPU availability, and CUDA extensions:

./scripts/uv.sh run python -m utils.verify_env --full

Common Setup Failures

SymptomCauseFix
uv not found on PATH uv is not installed or not visible in the current shell. Install uv first and reopen the shell, or export the directory containing uv into PATH.
nvcc not found on PATH The CUDA toolkit is not visible in the current shell. Set CUDA_HOME, export $CUDA_HOME/bin into PATH, or load the correct cluster module.
torch.version.cuda=... but nvcc=... PyTorch and the local CUDA toolkit do not match. Use CUDA 11.8 for this repo or recreate the environment after switching toolkits.
curand_kernel.h or other CUDA math headers missing NVHPC split-layout install without the math-root path configured. Set CUDA_MATH_ROOT and, if needed, add it to CPATH and LIBRARY_PATH.
Permission denied or broken cache state in uv The cache directory is unwritable or stale. Point UV_CACHE_DIR at a writable location, then rerun ./scripts/uv.sh sync --verify.
CUDA extension import fails after changing compilers or toolkit The existing environment was built against a different toolchain. Remove .venv and rerun ./scripts/uv.sh sync --verify from a clean shell.

3 Download Data

Download the CTA training release (Batches 1 & 2) from the TopBrain data page or directly from the Zenodo release, then unzip it into datasets/raw/: 

mkdir -p datasets/raw
curl -L \"https://zenodo.org/records/16878417/files/TopBrain_Data_Release_Batches1n2_081425.zip?download=1\" \
  -o datasets/raw/TopBrain_Data_Release_Batches1n2_081425.zip
unzip datasets/raw/TopBrain_Data_Release_Batches1n2_081425.zip -d datasets/raw
mv datasets/raw/TopBrain_Data_Release_Batches1n2_081425/{imagesTr,labelsTr}_topbrain_ct datasets/raw/

After unzipping you should have:

datasets/raw/
  imagesTr_topbrain_ct/
  labelsTr_topbrain_ct/

If your cluster blocks outbound downloads, fetch the ZIP locally, copy it to the cluster, and run only the unzip and mv steps there.

4 Generate Processed Datasets

The data generation pipeline converts raw CTA volumes into the training format: synthetic DSA projections, vessel priors, and optional residual point clouds for context-point initialization.

Generate a single case to test the pipeline:

uv run python -m data_generation.topbrain.cli --batch --limit 1 --output-root datasets/processed/topbrain

The pipeline reads paths from project.yaml:

paths:
  raw_datasets_dir: datasets/raw
  datasets_dir: datasets/processed
  results_dir: results

Each processed case produces a structured directory with views, priors, and residuals. See Dataset Format for the full output layout.

5 Train Your First Model

Train a 2-view reconstruction (AP + LAT) on a single TopBrain case:

uv run python train.py \
  -s datasets/processed/topbrain/topcow_ct_001/views/v2_ap_lat \
  -m results/2v_experiment \
  --Nviews 2 --seed 42

Prior and residual paths are auto-inferred from -s when the dataset follows the standard layout. For full control over loss weights and optimization, pass your own YAML file: 

uv run python train.py \
  --config path/to/your_config.yaml \
  -s datasets/processed/topbrain/topcow_ct_001/views/v2_ap_lat \
  -m results/2v_experiment \
  --Nviews 2 --seed 42

Key flags:

  • -s — path to the dataset folder containing transforms.json and projections
  • --Nviews — number of training views (must match the dataset)
  • --config — optional YAML file for loss weights, iterations, and optimization
  • --ply_path — CTA-derived vessel prior (auto-inferred if omitted)
  • --residuals_path — residual point cloud (auto-inferred if omitted)
  • --seed — random seed for reproducibility

Short smoke run:

uv run python train.py \
  -s datasets/processed/topbrain/topcow_ct_001/views/v2_ap_lat \
  -m results/2v_experiment_10k \
  --Nviews 2 --seed 42 \
  --iterations 10000 --densify_until_iter 5000

6 Evaluate

uv run python test.py -m results/2v_experiment --VQR --render_2d --seed 42

This produces:

  • 3D mesh metrics — Chamfer Distance and Hausdorff Distance in mm
  • Predicted vessel mesh — the reconstructed 3D vessel geometry as an OBJ file
  • 2D rendering metrics — PSNR and SSIM for the input projections
